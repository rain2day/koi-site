KOI Keyboard

為香港而設的中文鍵盤

倉頡、速成、筆劃、粵拼、注音——五種輸入方式共用同一個鍵盤。

手寫離線辨識，打字引擎完全不連網。

一筆滑過，就是一個字

下面並非影片，而是一個真正運作中的倉頡輸入法，就在你的瀏覽器內執行。用一筆滑過字根便能寫出整個編碼：途中掃到的鄰鍵會被略過，手指略為偏移一樣接得住——這正是 KOI 的核心。逐鍵點按同樣可以，使用電腦則可直接用實體鍵盤。

此示範需要啟用 JavaScript 才能運作。全站僅有的程式碼就是這個示範，而且不會連接任何伺服器。

編碼對照：hqi 是「我」，onf 是「你」，hda 是「香」，etcu 是「港」。

試著一筆滑過這幾組字根

  • hqi→我
  • onf→你
  • hda→香
  • etcu→港
  • nfwg→鯉

與 app 相同：滑行解碼，連容錯門檻、鄰鍵替代與轉角判定的數值都一致；鍵位排列、字根、候選次序（包括粵語字加權）、空白鍵輸出第一個候選、五碼上限，以及未開始組字時候選區顯示數字行。

示範沒有的部分：雙指和弦輸入、學習紀錄、另外四種輸入法，以及 z 萬用字元。滑行解不出結果時，app 會再跑一次救援搜尋，示範不會——所以胡亂滑一筆，它會直接告訴你沒有對應候選，而不是硬湊一個。字表亦收窄至 3,030 個常用字，並非 app 內完整的 27,584 個。

五種輸入方式，一個鍵盤

不必為了轉換輸入法，而在系統鍵盤清單中反覆翻找。五種模式都在 KOI 之內，切換即時完成。

字形

倉頡

原生鍵位排列，鍵帽同時顯示英文字母與倉頡字根。候選字按字頻排序，你經常選用的字會自動往前排。

字形

速成

首尾碼輸入。與倉頡共用同一套鍵位，不需要重新記憶鍵位。

字形

筆劃

五鍵筆劃輸入，支援 * 萬用字元——忘記中間幾劃，輸入一個星號一樣找得到。

拼音

粵拼

全拼與簡拼皆可，並可加上聲調數字收窄結果。輸出港式繁體中文。

拼音

注音（大千）

獨立注音鍵盤佈局，輸出台灣繁體中文。

同步解碼

英文

同一串按鍵會同時解碼為中文與英文候選，輸入英文不需要切換鍵盤。筆劃模式下停用。

實際畫面

以下兩張都是 KOI 執行中的實際擷取畫面，並非示意圖。

怎樣打都可以，不必遷就鍵盤

同一個組字之內，四種輸入方式可以混合使用。打到一半改變主意，也不需要清空重來。

點按、滑行、混合、雙指和弦

可以逐鍵點按，可以一筆滑過整串編碼，也可以先點按再接著滑行。兩隻手指同時按下也一併接收，全部歸入同一個組字。

滑行略有偏移仍然接得住

滑行解碼容許最多兩個鍵被相鄰鍵取代。手指稍為偏移，輸入不會因此中斷。

打錯碼不會落空

拆錯字時，KOI 會補上近似碼的候選，排在正常候選之後。候選區不會留下一片空白，讓你乾等。

刪除與游標

按一下刪去最後一個碼，連按兩下清除整個組字，長按不放則會加速。在空白鍵上左右掃動，可以移動游標。

手寫，不需要連網

手寫辨識模型直接封裝在 app 之內，不需要下載、不需要連線，飛航模式下一樣寫得到。

港式手寫模型

採用的是香港繁體手寫模型，而非普通話或簡體模型。你寫慣的字形，它認得出來。

水池筆跡

手寫區以 Metal 渲染成一池水：落筆有漣漪、有折射、有波紋。強度可在設定中調校，想要安靜一點就調低。

KOI Agent

需要時才開啟，不開啟就完全不存在。六種模式全部在鍵盤上完成，不必跳出去其他 app。

自動

讀取你眼前的內容，自行判斷該做什麼。

提問

直接發問，答案可以直接插入。

回覆

根據對方的訊息草擬一個回覆。

改寫

潤飾、調整語氣、翻譯。

貼圖

生成透明背景貼圖。

圖片

生成完整場景圖片。

打字引擎完全不連網

KOI 的輸入引擎——候選字產生、拆碼、學習紀錄——沒有任何網絡程式碼。你打的字不會離開你的裝置。

文字只會在一種情況下傳出：你主動開啟 KOI Agent 並送出請求。除此之外沒有例外。

  • 沒有分析工具、沒有崩潰回報 SDK、沒有廣告識別碼
  • 不會記錄你的按鍵
  • 學習紀錄與自訂設定留在裝置上，或存放於由你自己控制的私人 iCloud
  • 詳情見私隱政策

KOI Plus

免費版本已經包含五種輸入法、手寫、學習與全部基本輸入功能。Plus 另加兩項功能，並附送每月 Credits。

聯想輸入

輸出一個字之後，接著推薦下一個詞或整句短語，減少逐字拆碼。

跨裝置同步

設定與學習紀錄經你自己的私人 iCloud 同步。預設關閉；開啟之後由你手動按下同步，不會在背景悄悄傳送。

Credits 如何計算

訂閱附送
月費與年費計劃每個月發放 250 Credits。年費計劃是全年分十二次發放，而非一次全數發放。每批由發放日起 60 日內有效。
另行購買
Credit 包分 100、300、800 三種，屬一次性購買，不會過期，但不包括聯想輸入與跨裝置同步。
扣費時機
只有在你要求 KOI Agent 執行操作時才會扣減。日常打字不涉及 Credits。

AI 功能與剪貼簿貼上需要開啟「允許完整取用」。不開啟的話，五種輸入法、候選字、學習與手寫全部照常運作。詳情見支援頁。
