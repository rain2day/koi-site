# KOI Site

Static source for <https://koi.rainsday.com>.

## Validate locally

```bash
python3 scripts/verify_site.py .
```

## Ownership boundary

GitHub Pages deploys this repository through `.github/workflows/pages.yml`.
The base routes are live infrastructure, not final approval of product, Privacy,
Support, or KOI-specific Terms content. App Store metadata and app releases are
managed separately.
