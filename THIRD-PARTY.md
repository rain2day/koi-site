### Why the rest of the site is not LGPL

`assets/cangjie-data.js` is a standalone ES module. `assets/keyboard-demo.js`
imports two named exports from it and uses nothing else. The file can be
replaced with a differently-licensed dictionary of the same shape — two exports,
`RADICALS` and `TABLE` — without modifying any other file in this repository.

That separability is the condition LGPL-3.0 §4 sets for combining an LGPL'd
component with a work under other terms, so the remainder of this repository
stays under its own licence.

### Modifications made

The generator is committed at `scripts/build_cangjie_data.py` and its output is
committed rather than built at deploy time, so every change to the dictionary
appears as a reviewable diff. The transformations applied are:

- merging the Cangjie 3 and Cangjie 5 code sets into one table;
- restricting characters to the Basic Multilingual Plane;
- re-weighting candidate order by character frequency, including a Hong Kong
  Cantonese usage boost;
- dropping characters absent from Conway's ranking, and truncating each code to
  at most 12 candidates.

To regenerate:

```
python3 scripts/build_cangjie_data.py \
    --cin  ../urkeyboard/cangjie35_mobile.cin \
    --rank ../urkeyboard/ranking-traditional.txt
```

## Not used

This site loads no web fonts, no analytics, no tag manager, no CDN asset, and no
third-party frame, script, or stylesheet. `scripts/verify_site.py` enforces that
on every deploy: it rejects any `<script>` that is not either JSON-LD or a
first-party module, and scans the first-party modules for network and storage
APIs.
